新建一个 git 分支 `short_ver` 完成当前想法短文的撰写（如存在分支则切换即可）。原则包括：

1. 适当降低 novelty 和 solidity 的要求，即不必具备重大创新，验证也不必前沿详尽，展示完整的工作即可。
1. 尽量完全复用毕设中的工具设计和评估数据（包括图表），最大可能减少需要重新投入的资源。
1. 参考 main.tex 和 sections/ 下 full_ver 论文的想法，但是当工具和数据无法支撑我们最新的想法时回归到原始毕设的想法或表述，不要造假。

目标短文中文期刊的投稿要求在 ../期刊投稿指南与模板 。
应该套用目标模板撰写。

DOCX 模板编辑流程：

1. 复制目标期刊模板，不直接修改原始模板文件。例如：
   ```bash
   cp '../期刊投稿指南与模板/1_计算机系统应用/计算机系统应用_排版样例.doc' short_ver_template.doc
   ```
   如果模板是 `.doc`，先转换为 `.docx` 后再编辑。
2. 在模板副本中删除样例正文，但保留页面尺寸、页眉页脚、栏宽、字体、标题、摘要、关键词、表格和参考文献样式。
3. 将论文内容直接填写到模板副本中，优先使用模板已有样式，不自行新建相近但不一致的格式。
4. 使用 Word 或 LibreOffice 检查标题、摘要、关键词、正文、图表、公式、参考文献、分页和页数；同时导出 PDF 进行最终校对。
5. `short_ver.docx` 是最终投稿排版文件。`main.tex`、`sections/*.tex` 作为 full_ver 的参考，只读。
