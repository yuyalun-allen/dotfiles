# review contribution

你被要求评估一篇文章/工作的贡献，需要从以下三个相互独立的角度出发，分别给出判断。最后需要把评审报告写/更新到 review.md 中。

## 创新性（novelty）

我们站在人类已知的知识边界上看待这个问题。这不是一个完全老的问题——相关的东西是什么？这个工作试图解决哪些不一样的增量问题？

## 扎实性（solidity）

我们站在审慎的同行立场审视证据链。这个工作的结论是否由设计合理、对比公平、可复现的证据充分支撑？它是否如实划定了适用边界，让他人可以放心地在其上继续工作？

## 重要性（significance）

我们站在领域与实践的需求上看待这个问题。这个问题为什么值得解决、对谁有用？如果这个工作的结论成立，它会改变研究者或实践者的哪些认识与做法？
